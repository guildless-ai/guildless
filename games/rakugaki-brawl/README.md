# らくがきブロウル (Rakugaki Brawl) — prototype

描いた落書きがそのまま戦うオートバトル・ローグライト。インクは有限で、太く塗ればHP、トゲを描けば攻撃、軽く描けば素早さ、横に長く描けばリーチになる。色は三すくみ（赤>緑>青>赤、黒は無属性）。

形の特性（`src/parts.ts` の `traits`）: 閉じた輪＝盾（被ダメージ -1/輪、最大3）、胴体内の小さな輪＝目（1つでクリティカル +4%、2つで +8%）、脚＝速さ +0.1/本（最大4）、腕＝攻撃 +2/本（最大4）。小さな輪の角はトゲに数えない。特性は描いている最中にタグで表示される。

選定理由と市場根拠は [`../IDEAS.md`](../IDEAS.md)。

## 遊び方（開発中）

```sh
cd games/rakugaki-brawl
npm install
npm run dev      # http://localhost:5173
npm test         # 解析・戦闘ロジックのユニットテスト
npm run build    # 型チェック + 本番ビルド (dist/)
```

## 構成

- `src/analyze.ts` ストローク → ステータス（インク・トゲ・バウンディングボックス・支配色）
- `src/battle.ts` 決定論的な 1 対 1 シミュレーション（イベントログを返す）
- `src/enemy.ts` 同じルールで生成される手続き的な敵の落書き。胴体（丸・星・ミミズ）に目・脚・腕を予算内で足し、名前の接頭辞（めだま／あしつき／むかで／うでつき）は生成後の解析結果から付ける
- `src/run.ts` ラウンド・残機・インク上限曲線
- `src/perks.ts` 勝利後に 3 択で選ぶ強化（インク壺・とがった鉛筆・厚紙・速描き・一発芸・長い腕）
- `src/share.ts` 落書きを URL セーフな共有コードに変換。貼った相手の絵が次の敵になる（サーバ不要の非同期対戦）。形式 RB2 はバイナリ（先頭点は絶対値、以降は zigzag varint の差分、2.5px 未満の点は間引き）で、旧テキスト形式 RB1 の約 1/8。RB1 も読める
- `src/gallery.ts` 勝った絵を localStorage に最大30件保存。ラウンド2,5,8…では近いラウンドの過去作が「むかしの自分」として敵に出る
- `src/main.ts` お絵描きパッドとリプレイ描画（DOM 依存はここだけ）

- `src/anim.ts` イベントログから各時刻のポーズ（踏み込み・伸縮・傾き）を純粋関数で算出。攻撃＝予備動作→踏み込み→戻り、被弾＝吹き飛び＋潰れ（大ヒットは一回転）、KO＝横倒れ
- `src/arena3d.ts` three.js の紙切り抜き 3D アリーナ。落書きを薄い板メッシュにして透視カメラで描画、影・カメラ揺れ・ダメージ表示つき。WebGL が無い環境は `src/arena2d.ts` の平面描画に自動で切替
- `src/parts.ts` 絵を幾何だけで「胴体・脚・腕」に分解。胴体＝最もインクの多いストローク（＋その内側や同程度のもの）、脚＝胴体より下に伸びる縦長の線、腕＝胴体より横に突き出た線。脚は上端、腕は胴体に最も近い点を支点に回転
- `src/anim.ts` の `limbPoseOf` で局面ごとに手足の角度を決める。歩行＝脚が交互に振れ腕は逆位相、攻撃＝腕を後ろに引いてから前へ振り抜く、被弾＝ばたつき、KO＝手足が垂れる
- `src/render.ts` の `makeFrameFactory` が毎フレーム「手足を回転 → 線を数px揺らす（手描きボイル）→ ラスタライズ」し、3D ではその canvas をテクスチャとして更新

- `src/sfx.ts` Web Audio で合成する効果音（素材ファイルなし）。振りかぶりのヒュッ、ヒットのノイズ＋低音、勝利アルペジオ、敗北の下降音。最初のクリックで AudioContext を作る

演出: クリティカルと効果大のヒットでヒットストップ（90ms）と画面揺れ、被弾側は一瞬白く光る。決着後は敗者が横倒れ、0.5秒後に勝者が2回ジャンプして腕を振り、結果バナーが弾む。手足を振っても最下点が常に接地するよう毎フレーム補正。

## 放置モード（セカンドモニター）

「放置モード」ボタン、または `?idle` 付き URL で起動。UI を畳んで 960×220 の横長ストリップにし、今の絵（無ければギャラリーの過去作）が生成敵の無限ウェーブと戦い続ける。2ウェーブごとに敵の予算が上がり、ラウンド10相当で頭打ち。wave・勝数・連勝・最高連勝は localStorage に保存され、次回も続きから。音は鳴らさない。Rusty's Retirement 型の「作業中に画面端で動く」導線（`src/idle.ts`）。

## デスクトップ版（Electron）

```sh
npm run electron      # 開発: dist/ を読み込むので先に npm run build
npm run dist:win      # electron-builder で Windows 用 nsis / zip を release/ に出力
npm run dist:mac      # dmg
npm run dist:linux    # AppImage
```

`electron/main.cjs` がメインウィンドウを開き、「放置ウィンドウ」ボタン（Electron 内でのみ表示）で、作業領域の最下部に幅いっぱい・高さ260px・常に最前面・枠なしのストリップウィンドウを `?idle=1` で開く。レンダラーは `contextIsolation` + `sandbox` 有効で、プリロードは「放置ウィンドウを開く／閉じる」だけを公開する。Vite は `base: './'` で file:// から読める。`RAKUGAKI_SMOKE=1` で起動すると両ウィンドウを開いて状態を JSON 出力して終了する（CI 用）。

Steam 配布時は steamworks.js を Electron のメインプロセスに足し、実績とクラウドセーブ（ギャラリーと放置の進捗）をつなぐ。ゲーム側は `src/platform.ts` の `PlatformServices`（`unlock` / `unlocked` / `storage`）だけを使うので、`LocalPlatform`（localStorage）を Steam 実装に差し替えるだけでよい。

## 実績と放置モードの報酬

実績6種（はじめての勝利・完走・フル装備＝盾目脚腕そろい・過去を超える＝むかしの自分に勝つ・ともだちと＝共有コードの絵と戦う・放置の達人＝放置5連勝）。解除時はアリーナ上部にトーストを出し、ログにも残す。放置モードは5勝ごとに「インク壺」を1つ銀行（最大3）し、「最初から」で新しいランを始めるときに `ink` 強化として持ち込む。

## ランの結果カード

ランが終わる（残機0 か 10ラウンド完走）と、`src/summary.ts` が 1200×630（SNS カード比率）の画像を描く。タイトル（完走！ N勝／Nラウンド N勝で力尽きた）、各ラウンドで使った絵のサムネイルに ○×△ と相手の名前、`#らくがきブロウル`。「画像を保存」で PNG ダウンロード、「画像をコピー」でクリップボードへ、「対戦リンクをコピー」で最後に勝った絵（無ければ最後の絵）の共有コードを `?code=` に埋めた URL をコピー。リンクを開くとその絵が次の相手として読み込まれる。切り抜き・SNS 共有の導線。

音量スライダー（0 でミュート）は localStorage に保存され、Web Audio のマスターゲインに反映される。
