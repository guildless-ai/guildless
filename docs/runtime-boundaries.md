# Runtime boundaries

1. **Discovery** may read only sources explicitly allowed for the current company run.
2. **Evidence** is append-only for a run; a claim without a source is an inference, not a fact.
3. **Acquisition** can discover candidates but cannot silently install or execute them.
4. **Execution** is capability-specific and permission-gated. External effects remain stopped until approval.
5. **Verification** measures the resulting system and stores machine-readable evidence.
6. **Money ledger** counts only verified cash events, never leads, replies, meetings, or contracts as revenue.
7. **Memory** can store reusable conditions and outcomes, but not secrets or irreversible state.
